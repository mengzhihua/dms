# DMS 亮点

DMS 面向经销商网络，把整车销售、维修、备件和满意度放在门店这一侧。

1. **门店主链路是通的。** 从整车库存、销售订单、预约、维修工单、质检结算，到满意度回访和经销商考核。
2. **维修指导能按故障推荐。** 故障码、症状、车型参与打分，工单可以一键带入工时和步骤，并做在线估价。
3. **备件缺货会变成向订单系统的补货单。** 按经销商从缺货生成补货，再按下发。没有缺货时不会空开一张单。
4. **满意度低分会变成投诉。** 调研可以是分数、NPS 或文本，低分自动进入投诉处理，而不是只停在一张问卷上。
5. **控制塔看的是缺货和补货，不改维修工单。** 有开放密钥走指令口；只有账号时，登录后按经销商生成、按补货单号下发。整车订单和工单仍在本系统里处理。
